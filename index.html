Install

Sixty seconds to set it up

Clone it, point it at any database, and register it with your MCP client. The agent gets the toolkit; you get the report.

setup 
# 1 — get it
git clone https://github.com/ashishsinha1602/AshishSinha
pip install -r requirements.txt

# 2 — point at any database (Postgres or Oracle wallet)
cp .env.example .env   # add DATABASE_URL or ORACLE_* vars

# 3 — register with Claude Desktop / Claude Code
{ "mcpServers": { "db-detective":
  { "command": "python", "args": ["server.py"] } } }

# then just say:  /investigate the database
