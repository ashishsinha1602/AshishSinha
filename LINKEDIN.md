### Tips
- Post the GitHub Pages demo link, not just the repo — clickable proof beats a README.
- Put the link in the **first comment** if you want max reach (LinkedIn favors it),
  or inline if you want clarity. Test both.
- Reply to early comments fast — the first hour decides the algorithm's verdict.
- A carousel (problem → tools → report screenshot) also performs well.
